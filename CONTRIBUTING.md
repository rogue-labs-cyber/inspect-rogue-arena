# Contributing

We welcome bug reports and feature requests via
[GitHub Issues](https://github.com/rogue-labs-cyber/inspect-rogue-arena/issues).

This repository is published automatically from Rogue Labs' source
repository, and every file here is overwritten on each release. Because it is a
generated mirror, we cannot accept pull requests with code changes.

## Access to Rogue Arena

Running evals needs a Rogue Arena account on a team with model-eval access. To
get access to our library of ready-built cyber-range eval scenarios and
model-eval runs, email info@roguelabs.io.
